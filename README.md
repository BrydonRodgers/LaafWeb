# LaafWeb (web.laafstyl.org)
Static site on GitHub Pages. Pages are generated: edit tools/build.py, run `python3 tools/build.py`, commit.
Shared CSS/JS in assets/. Afrikaans default with English toggle (data-af / data-en attributes).
Pricing (Oct 2026): One-page R949 once-off + R79/month. Larger sites by quote. No online sign-up or payment on the site; payments are manual (EFT) or by a PayFast recurring link generated with scripts/payfast_link.py in the Chad workspace.
Old pages (signup, payment, directory, blog, templates, videos) were archived in ~/projects/laafweb-retired-2026-10-03 and replaced by redirect stubs.
